# Fonts

All three families are licensed under the SIL Open Font License 1.1 and
were obtained from the Google Fonts repository (github.com/google/fonts):

- **B612 Mono** — commissioned by Airbus for cockpit-display legibility;
  used for numerals, airport codes, and metadata. © The B612 Project Authors.
- **Barlow** — display headings. © The Barlow Project Authors.
- **Public Sans** — body text. © General Services Administration (USWDS).

The `.ttf` files here feed matplotlib; the Latin-subset `.woff2` files in
`docs/fonts/` are served by the GitHub Pages site.
